🔬 Erradicación del Cuello de Botella en CPU 0 (CPU 0 Bottleneck)

En configuraciones de Windows por defecto, múltiples controladores PCIe comparten líneas de interrupción legadas (Line-Based IRQ), lo que obliga a la CPU a interrumpir el Core 0 de forma síncrona para consultar qué dispositivo originó la interrupción. Con Message Signaled Interrupts (MSI/MSI-X), cada dispositivo escribe directamente en un vector de memoria dedicado de la CPU mediante transacciones de bus PCIe DMA, eliminando la contención de interrupciones y permitiendo a la GPU y al almacenamiento NVMe procesar transferencias en paralelo.
